# Project Sol V5 — Everyone Has an Idea

V5 includes:

- Mission-first homepage
- Talk, type, or explore entry points
- Voice input and read-aloud prompts
- Audience selection
- Step-by-step project roadmap
- Local Idea Garden
- Kid-friendly and mobile-responsive design
- Legal and security files

Important:
This is still a front-end prototype. Idea Garden entries are stored only in the visitor's browser.
Real accounts, shared projects, live AI, moderation, email, and a shared database require a secure backend.
