Bring SOL to life.

This button opens Vercel, connects your GitHub repository, asks for your private OpenAI API key, and deploys the live AI website.

Deploy Project SOL
Before tapping: the newest Project SOL files must already be uploaded to the root of mojojo1990-debug/joinprojectsol.org.
  1. Tap Deploy Project SOL.
  2. Sign in to Vercel with GitHub.
  3. Paste your private key into OPENAI_API_KEY.
  4. Leave OPENAI_MODEL set to gpt-5-mini.
  5. Tap Deploy.

Your API key is entered directly into Vercel. Do not put it in GitHub, screenshots, messages, or website files.
