# joinprojectsol.org — Static Community Preview Release

Current website: bilingual, static, human-first concept preview.

Features: responsive public homepage, bilingual toggle, proposed community network visualization, the browser-local First-Step Studio, copy/download of plans, installable manifest, and offline fallback.

**Removed:** live AI chatbot, server-side AI gateway, AI API tests, old chat browser code, and AI deployment launcher. No OpenAI model key is required to host this website.

The site does not represent an incorporated nonprofit, operating training center, or a launched social network. Any future opportunity directory or community services need real-world testing and privacy reviews.

Technical deployment: GitHub Pages from `main`. Verify the deployment workflow and perform a mobile browser smoke test after every release.
