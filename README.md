# Project Sol V4 — Interactive App Prototype

Included:
- Local prototype signup/login
- Interactive AI Builder roadmap
- User-created project gallery
- Animated space design
- Mobile-responsive layout
- Existing legal/security files

Important:
This is a front-end prototype. Account and project information is stored only in the visitor's browser. Real authentication, databases, email verification, payments, and AI require a secure backend service and private API keys.


## Voice Builder update

- Large animated microphone button designed to stand out for children
- Speech-to-text for kids and visitors who cannot spell their ideas
- Read-aloud prompt button
- Kid-friendly tap-to-start project ideas
- Clear microphone permission and error messages

Voice recognition depends on the visitor's browser and microphone permission.
